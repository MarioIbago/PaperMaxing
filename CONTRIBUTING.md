# Contributing to PaperMaxing

Thanks for contributing.

## Principles

1. Provenance first: facts about a paper need a recoverable source pointer.
2. Provider-agnostic domain code.
3. Portable: features should not require Vercel to work in self-host mode.
4. Accessible UI.
5. Do not collapse evidence quality into a single truth score.
6. Abstention is a valid result when a claim cannot be verified.

Pull requests should document motivation, mobile/desktop behavior for UI changes, tests or fixtures for parsing/AI changes, new environment variables, and local/cloud impact.
