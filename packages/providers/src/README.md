# Providers

Provider-specific SDK and wire-format details belong here, outside the domain layer.

Planned adapters include OpenRouter, OpenAI, Anthropic, Google Gemini, Ollama, generic OpenAI-compatible endpoints, OpenAlex, Crossref, Semantic Scholar, Unpaywall, local/S3-compatible storage, and job runners.

NotebookLM is modeled separately as a persistent grounded research provider rather than a stateless text-generation provider.
